API de Gestão de Agências

Bem-vindo à documentação oficial. Abaixo você encontra os recursos disponíveis para consulta e cadastro de unidades.

GET /agencias

Listar todas as agências

O que o usuário pode fazer: Retorna uma lista completa com todas as agências cadastradas no banco de dados. Ideal para preencher painéis de controle, tabelas de visualização, listagens em aplicativos ou plotar localizações em um mapa.

GET /agencia/:id

Buscar uma agência específica

O que o usuário pode fazer: Busca os detalhes completos de uma única agência utilizando o seu ID identificador único na URL. Utilize esta rota quando precisar carregar a página de perfil ou os dados de contato específicos de uma unidade.

POST /agencia

Cadastrar nova agência

O que o usuário pode fazer: Cria um novo registro de agência no sistema. O usuário deve enviar os dados da unidade no corpo da requisição (Body) em formato JSON.

Exemplo de Payload (JSON)

{
  "nome": "Agência Central",
  "endereco": "Av. Rio Branco, 156 - Centro",
  "cidade": "Rio de Janeiro",
  "estado": "RJ",
  "cep": "20040-003",
  "status": "ativa"
}
